## Common Pitfalls to Avoid

### ❌ Data Quality Issues
- **Problem:** Look-ahead bias, survivorship bias
- **Solution:** Use adjusted prices, include delisted securities
- **Test:** Walk-forward analysis

### ❌ Overfitting
- **Problem:** Strategy fits historical data too well
- **Solution:** Out-of-sample testing, parameter robustness
- **Test:** Same strategy on different assets/periods

### ❌ Transaction Costs
- **Problem:** Ignoring slippage, commissions
- **Solution:** Realistic cost modeling (2-5 bps typical)
- **Test:** Compare with/without costs

### ❌ Optimization Overfitting
- **Problem:** Optimizing too many parameters
- **Solution:** Limit parameters, use penalization
- **Test:** Parameter sensitivity analysis

### ❌ Survivorship Bias
- **Problem:** Using index data (deleted companies)
- **Solution:** Use universe that includes delisted
- **Test:** Compare with total market return
